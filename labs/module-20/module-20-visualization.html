20.3 Decision points (answer these before you write YAML)

Click each decision to walk the reasoning.

Same build shape across services?
→ reusable workflow vs per-service workflows
Cloud credentials in use today?
→ OIDC adoption (replaces every service connection)
Who approves production?
→ environment gate ownership (Module 13)
Monorepo or many repos?
→ matrix vs path-filtered workflows (Module 07)
Do we need self-hosted runners?
→ GitHub-hosted first, self-hosted only if justified (Module 03)

20.4 Parallel-run & cutover (the safest migration is not a big-bang)

Click each phase to see the cutover tactic.

Weeks 1–2port 1–2 low-risk pipelines; ADO + Actions side-by-side on the same repos
Weeks 2–4port remaining CI; enable Actions status checks on branch protection
Week 4+cutover CD + env gates; decommission ADO behind a runbook
Rollback path: a reverted branch-protection rule restores ADO as the gate in minutes. Keep ADO alive until branch protection is fully moved — and define the revert runbook in advance.
