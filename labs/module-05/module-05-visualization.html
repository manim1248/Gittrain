5.1 Where Copilot helps — three surfaces

⌨
Inline suggestions
As you type YAML in VS Code, Copilot proposes the next chunk — Tab to accept. Great for fleshing out a workflow you already started.
💬
Copilot Chat
Ask in natural language: "scaffold a CI workflow for a Node 20 service", "explain this action", "refactor steps 2–4 into a composite action".
❯
Copilot CLI (gh copilot suggest)
Describe a workflow in the terminal; get a ready-to-paste YAML. Handy when you're not in the editor.

5.4 Prompt cheat-sheet

  

    
GoalPrompt opener

    
Scaffold"Create a GitHub Actions workflow that . It should . Use . Pin third-party actions by SHA, set least-privilege permissions…"

    
Explain"Explain this workflow job by job. What runs, on what, and why? Flag anything insecure or risky."

    
Action research"What does  do? Inputs, outputs, required permissions, latest stable ref, verified publisher?"

    
Refactor"Extract steps X–Y into a composite action at . Preserve inputs/behavior. Add shell: to every run: step."

    
Migrate"Convert this azure-pipelines.yml to GitHub Actions using jobs + needs. Map stages to needs-chains. Flag steps with no Actions equivalent."

    
Debug"Here is a failed run log: . Root cause + a PR-ready YAML fix, with each change explained."
