4.1 Pinning policy — how should I reference an action?

Every action you pin is third-party code that runs inside your CI. Your choice of @ref is a security decision, not a style choice.

Full commit SHA
uses: actions/checkout@dcd71f6466…
Major version tag
uses: actions/checkout@v4
Floating tag / branch
uses: some-user/some-action@main
Recommended policy: pin third-party actions by full SHA, with the tag in a comment (# v4.x.y). Let Dependabot keep the pins current. Treat floating refs as the exception for trusted first-party actions only — and never on branches.
