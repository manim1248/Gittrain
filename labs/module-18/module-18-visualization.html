18.2 The discover → fromJSON pattern (the pipeline grows itself)

A discover job computes which services changed; the build job expands the matrix from its output. Add a service to the manifest and the pipeline adapts with zero workflow edits.

services manifestsource of truth
→
discoverreads + emits JSON matrix
→
fromJSONexpand at run time
→
build cellsN services in parallel
→
push + deployper service

  
Generate vs reuse (Module 10): a reusable workflow parameterises at run time — ideal for the 80% common path. Generation emits per-service YAML — ideal when repos differ enough that the with: surface gets awkward. Many teams: reusable workflow for the common path, generation for the org-wide scaffold.
