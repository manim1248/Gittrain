6.1 Expression resolver — click a token (ADO: $(Build.SourceBranch) ≈ ${{ github.ref }})

GitHub evaluates ${{ … }} expressions before a run starts. Each context exposes a different slice of data. Click a token below to see what it resolves to for this simulated run.

Where you'd write it

run: echo "Building branch ${{ github.ref }}"
    docker build -t img:${{ github.sha }}

  REGISTRY: ${{ vars.IMAGE_REGISTRY }}

When is it resolved? github / vars / secrets resolve at workflow start. env resolves just before a step runs. needs / matrix only exist in jobs that declare them.

6.4 Where secrets & variables live (ADO: repo vars ≈ variable groups)

  
Non-secret config goes in vars, sensitive values go in secrets. Both come from Settings/UI/CLI — never from the workflow file. Click a storage box to see how it's referenced.

6.5 $GITHUB_ENV — the persistence trick (ADO: ##vso[task.setvariable])

  
Each run: step is its own shell — an export dies with the step. Writing to $GITHUB_ENV persists a value to all later steps in the same job. Watch the value survive.
